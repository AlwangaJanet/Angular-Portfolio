CitizenConnect Web Application

Description: Developed CitizenConnect, a civic engagement web platform inspired by the 2024 protests in Kenya.
The application empowers citizens to report incidents and share their views—optionally with photos—while
allowing government officials and admins to monitor, summarize, and respond using AI-powered insights.
Tech Stack: Angular, Node.js, MSSQL
Key Features:
Multi-role system supporting three user types: Citizens, Government Officials, and Admins.
Citizens can submit and view reports of incidents with optional image attachments.
Government officials access summaries and trends via AI-generated analysis.
Admin dashboard for managing content, users, and reports.
Secure login/signup system and responsive design across all device types.

Predicting Youth Unemployment Barriers in Kenya Using AI

Description: This project uses a synthetic dataset of Kenyan youth to train a machine learning model that analyzes personal descriptions of job-seeking experiences. It predicts the main barrier to employment—such as a skills gap or lack of opportunities—and recommends targeted interventions.
Goal: Support policymakers, job placement programs, and youth empowerment initiatives with AI-driven insights.
Tech Stack: Python, Flask, Scikit-learn, Pandas
Key Features:
- AI model predicts key employment barriers based on text input.
- Tailored intervention suggestions to address specific challenges.
- User-friendly interface for entering job-seeking experiences.
- Deployed on Render
